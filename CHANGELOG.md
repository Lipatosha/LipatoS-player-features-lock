# История изменений

## 1.0.3

- Добавлена совместимость с D&D5e 6.0.5.
- Обновлены манифест и установочный архив модуля.
- Рабочая логика модуля сохранена без изменений.

## 1.0.2

- Текущая рабочая версия перенесена под название LipatoS.
- Игрокам запрещено изменять поля во вкладке «Особенности».
- Сохранена подсказка «Только ГМ может активировать» при наведении.
- Сохранено исключение для селектора уровня класса, если ГМ разрешил его через модуль редактирования уровня.
- Добавлена совместимость с новым флагом `lipatos-player-level-edit` и старым `aindor-player-level-edit`.
- ГМ и Assistant GM не ограничиваются модулем.
