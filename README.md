# LipatoS — Блокировка особенностей игрока

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который запрещает обычным игрокам изменять поля во вкладке **«Особенности»** карточки персонажа.

Исключение — выбор уровня класса, если ГМ отдельно разрешил его через модуль **LipatoS-player-level-edit**.

## Версия

**1.0.2**

## Совместимость

- Foundry VTT: **14**
- D&D 5e: **6.0.0–6.0.3**

## Возможности

- блокирует ввод, селекторы, текстовые поля и переключатели во вкладке **«Особенности»**;
- поддерживает стандартные и ApplicationV2-листы D&D 5e;
- показывает подсказку **«Только ГМ может активировать»** при наведении на заблокированный элемент;
- не делает элементы визуально неактивными — внешний вид сохраняется;
- разрешает селектор уровня класса, если ГМ включил соответствующее разрешение;
- для ГМ и Assistant GM ограничения не применяются.

## Совместимость с модулем уровня

Модуль использует флаг **LipatoS-player-level-edit**. Для плавного перехода также поддерживается старый флаг **aindor-player-level-edit**.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-player-features-lock/main/module.json`
